# 02 — 100 premium apps that are not note apps

These are the objects people call "the best designed apps." We are stealing *feel*, not features. Score is **transfer value into an Android notes app**.

## How premium actually feels (after this list)

Premium is usually four things at once:

1. **Fewer destinations.** The app is a surface, not a mall.
2. **One hero action.** Always obvious.
3. **Material or light that belongs to the OS**, plus one signature accent.
4. **Motion and haptics that confirm, never decorate.**

Apps that fail "premium" even when they are famous: Instagram (crowded), Spotify 2025 (too many rails), Notion mobile (toolbox), most neobanks after year 3 (promotion banners).

## Transfer rules for Notesup

From this hundred, only a few patterns are allowed onto the home screen:

| Pattern | From | Notesup use |
|---|---|---|
| Hero action | Shazam, Drafts, Keep | New note FAB / split FAB |
| Pill filters | Airbnb, Apple Music, Expressive Google apps | All / Pinned / Recent / Projects |
| Soft grouped lists | Things 3 | Project view |
| Big type, few buttons | Cash App, Hello Weather | Empty home, editor title |
| Card as object | Wallet, Craft, Darkroom | Note tile |
| Status color | Linear, Flighty, Copilot | Pin, sync, lock — never decoration |
| Command bar | Raycast, Superhuman, Linear | Search that runs verbs (`pin`, `pdf`, `project:`) |
| Haptic recognition | Copilot, Apollo, iOS cameras | Pin, check, create, delete |
| Constraint | reMarkable, BeReal, Niagara | No fifth tab |
| Timeline | Flighty, Structured | Recent |
| Widget as product | Google Clock, Keep, Pixel | New + pinned + list |

## Hard rejects imported from premium apps

- Superhuman's custom non-OS chrome on Android (we are Expressive, not a skin)
- Instagram's five destinations
- Revolut/Spotify module salad
- Fitness rings as gamification of writing
- TikTok full-bleed as the note editor
